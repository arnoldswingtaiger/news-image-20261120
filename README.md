One image summing up the world news of Friday 20 November 2026: Cyclone Akvan slamming into India's east coast with more than 300,000 people evacuated, Trump deferring any Iran decision to next year, the UN court's genocide ruling against Myanmar over the Rohingya, Anthropic's shares soaring 17% in the biggest IPO on record, a Houthi missile hitting Riyadh's tallest tower, COP31 closing in Antalya without a fossil-fuel pledge, and Europe's allies saying they are ready for talks with Russia.

`main.py` draws the 1024×1024 image from scratch in pure Python 3 standard library — its own PNG encoder and a built-in 5×7 bitmap font, no network, no installed packages — and writes it to `/output/entry.png`. Deterministic: no clock, no randomness, so two runs write the same bytes.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```
